## ChatGPT Plus — uso de dados para treino

### Resposta direta: **por padrão, não — mas depende de uma configuração.**

---

### Como funciona

| Conta | Padrão | Pode mudar? |
|---|---|---|
| **Gratuita** | Dados **usados** para treino | Sim, opt-out nas configurações |
| **Plus (paga)** | Dados **não usados** para treino | Sim, opt-in voluntário |
| **Team / Enterprise** | Dados **nunca usados** | Não alterável |

---

### Como verificar na sua conta Plus

1. Clique no seu nome (canto inferior esquerdo)
2. **Settings → Data controls**
3. Veja o item **"Improve the model for everyone"**
   - **Desligado** = seus dados não são usados para treino ✅
   - **Ligado** = são usados

---

### Atenção importante

Mesmo com treino desativado, a OpenAI **ainda armazena e processa** suas conversas para fins como:
- Segurança e moderação
- Suporte técnico
- Cumprimento de obrigações legais

Portanto, **dados sensíveis — como documentos jurídicos com informações de clientes — não devem ser colados mesmo no Plus**, a menos que você use a versão **Enterprise** (que tem contrato específico de confidencialidade) ou a **API com opção de não retenção** (`no-log`).

---

### Para o caso do documento que você anonimizou

A anonimização que você fez é exatamente a prática correta antes de usar qualquer IA de terceiros, independentemente das políticas de treino.
