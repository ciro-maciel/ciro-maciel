## Código aberto

**[Cleaner](https://github.com/ciro-maciel/cleaner)**: o limpador de Mac que mostra antes de apagar.
As regras ficam num arquivo que dá para ler, tudo o que sai passa 7 dias numa quarentena, e o app não
tem uma linha de código de rede. MIT.

Em volta, de graça: [ferramentas no navegador e apps de Mac](https://ciromaciel.click/tools?ref=github-profile),
[extensões para o VS Code](https://open-vsx.org/namespace/ciro-maciel) e para o Chrome, e os livros da
série [O Novo Básico](https://ciromaciel.click/books?ref=github-profile).

## Como isso é operado

Uma pessoa, com agentes, em produção. Cada agente tem um cargo, um nível de confiança e uma métrica que
diz se ele serve. O agente escreve, testa e prepara; publicar, enviar mensagem e cobrar ficam com uma
pessoa.

O que eu aprendi fazendo isso está publicado para copiar:

- [Regras para o CLAUDE.md](https://ciromaciel.click/rules?ref=github-profile), cada uma com o erro que a fez nascer
- [Agentes com cargo](https://ciromaciel.click/agents?ref=github-profile), com o arquivo do agente e o que ele nunca faz
- [Pedidos prontos](https://ciromaciel.click/prompts?ref=github-profile), cada um com o teste ao lado
