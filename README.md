# Ciro Cesar Maciel

**Construir é de todos. As ferramentas e o saber é que não eram.**

Faço software há mais de **vinte anos**. Hoje construo, sozinho e com agentes, os blocos que uma ideia precisa para existir de verdade. São **16 produtos no ar**, em **quatro linhas**; **18 ferramentas grátis**, **5 delas apps de Mac**; **6 livros publicados**; e o **primeiro projeto de código aberto**. Tudo feito por **uma pessoa**. E eu mostro como usar.

**As linhas.** [Infrastructure](https://myinfrastructure.click/?ref=github-profile), a infraestrutura que os agentes já sabem operar · [Operations](https://myoperations.click/?ref=github-profile), o que acontece no que você colocou no ar · [Customers](https://mycustomers.click/?ref=github-profile), onde cada pessoa está · [Marketing](https://mymarketing.click/?ref=github-profile), o que trouxe cada pessoa.

**Código aberto.** [Cleaner](https://github.com/ciro-maciel/cleaner), o limpador de Mac que mostra antes de apagar: regras legíveis, 7 dias de quarentena e nenhum código de rede. MIT. De graça também: [ferramentas e apps de Mac](https://ciromaciel.click/tools?ref=github-profile), [extensões do VS Code](https://open-vsx.org/namespace/ciro-maciel) e os [livros](https://ciromaciel.click/books?ref=github-profile).

**Como é operado.** Cada agente tem cargo, nível de confiança e uma métrica que diz se ele serve. Publicar, enviar mensagem e cobrar ficam com uma pessoa. Está aberto para copiar: [regras para o CLAUDE.md](https://ciromaciel.click/rules?ref=github-profile), [agentes com cargo](https://ciromaciel.click/agents?ref=github-profile) e [pedidos prontos](https://ciromaciel.click/prompts?ref=github-profile).
