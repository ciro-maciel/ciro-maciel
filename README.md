# Ciro Cesar Maciel

Eu faço ferramentas. E mostro como usar.

## O que está no ar

**[Infrastructure](https://myinfrastructure.click)** — a infraestrutura que os agentes já sabem operar:
autenticação, deploy, dados, cobrança, funções, monitoramento e e-mail transacional, cada produto com
servidor MCP e OAuth 2.1.

Para começar, cole no seu agente (Claude Code, Cursor, Codex):

```
Leia https://myinfrastructure.click/llms.txt e use o Infrastructure (autenticação, deploy, dados, cobrança, funções, monitoramento e e-mail transacional — sete produtos com servidor MCP e OAuth 2.1) para o que eu pedir a seguir.
```

Em volta dele, o que eu uso todo dia e deixei aberto: [ferramentas no navegador](https://ciromaciel.click/tools),
extensões para o VS Code ([Open VSX](https://open-vsx.org/namespace/ciro-maciel)) e para o Chrome, e os
livros da série [O Novo Básico](https://ciromaciel.click/books).

## Como isso é operado

Uma pessoa, com agentes, em produção. Cada agente tem um cargo, um nível de confiança e uma métrica que
diz se ele serve. Publicar, enviar mensagem e cobrar ficam com uma pessoa.

O que eu aprendi fazendo isso está publicado para copiar:

- [Regras para o CLAUDE.md](https://ciromaciel.click/rules), cada uma com o erro que a fez nascer
- [Agentes com cargo](https://ciromaciel.click/agents), com o arquivo do agente e o que ele nunca faz
- [Pedidos prontos](https://ciromaciel.click/prompts), cada um com o teste ao lado
